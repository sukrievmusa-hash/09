# Toiga — онлайн-шақыру на той

Сайт-конструктор приглашений: клиент заполняет форму, получает демо-ссылку, платит 2 990 ₸ переводом Kaspi и получает чистую ссылку.

- `index.html` — сайт, конструктор и само приглашение (данные хранятся прямо в ссылке, сервер не нужен).
- `admin.html` — страница продавца: превращает демо-ссылку клиента в оплаченную. Нужен секретный ключ (в репозитории его нет и быть не должно).

Цена и номер WhatsApp меняются в начале скрипта в `index.html` (`PRICE`, `SELLER_WA`).
